# Snake (better)

The enhanced Snake experience. Same features as `snake-good/`: Play, Leaderboard, Profile, About — wired to the same `/api/v2` high-score API and the same `snake.profile` localStorage key.

## Run

1. API: `cd ../server && npm install && npm start`
2. Here: `npm install && npm run dev`
3. Open http://localhost:5174

## Notes

- Mystery-meat icon nav, permanent privacy strip, promotional overlays with working Close
- Leaderboard search/sort controls are opinionated
- Profile uses advanced input widgets (sliders, large selects, hex entry)
- Your snake is personalized: body segments show letters from your profile name
