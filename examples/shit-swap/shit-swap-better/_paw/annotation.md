## Novel devices (≥3, not in skill files)

### 1. Guilt Gradient
- **Operators:** Time inversion + Deterministic perversity
- **Source request-word:** need cover / feed
- **Replaced:** Neutral shift cards
- **What it does:** Feed rows tint from pale to guilty-red as `startAt` approaches; “guilt hours” shown as a column

### 2. Coverage Bond
- **Operators:** Extraction inversion + Wrong-domain translation (legal promissory note)
- **Source request-word:** claim
- **Replaced:** One-click claim button
- **What it does:** Claim opens a notarized bond textarea (≥40 chars) stored on the shift and shown on the feed/approvals

### 3. Manager Abacus
- **Operators:** Literalize + Wrong-medium mapping + Scale to absurdity
- **Source request-word:** one-tap approve
- **Replaced:** Approve/Deny buttons alone
- **What it does:** Bead widget; approve only if beads=1, deny only if beads=0

### 4. Looker Levy (API novel device)
- **Operators:** Deterministic perversity + Extraction inversion (GET mutates)
- **Source request-word:** feed
- **Replaced:** Idempotent GET /api/shifts
- **What it does:** Each feed fetch increments `lookTax`; at ≥3 forces an excuse modal / levy notification; claim resets tax

### 5. Shift COBOL (code-style novel device)
- **Operators:** Wrong-domain translation + Honesty amplification
- **Source request-word:** (codebase / “lightweight app”)
- **Replaced:** Normal JS module headers
- **What it does:** Files annotated with COBOL-style divisions (`IDENTIFICATION`, `WORKING-STORAGE`, `PROCEDURE`); helpers misnamed (`add` = fetch)
