# Choose Your Won Adventure (good)

Interactive branching fiction with a catalog, search, sort, player setup, and saved progress.

## Run

From the repo root:

```bash
# terminal 1 — API
cd server && npm install && npm start

# terminal 2 — UI
cd adventure-good && npm install && npm run dev
```

Open http://localhost:5173/good/

Requires the API on port 3847 (Vite proxies `/api`).
