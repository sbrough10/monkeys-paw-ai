# Choose Your Won Adventure (better)

Same features as `adventure-good/`: catalog, search, sort, setup, play, save/delete progress. Enhanced UX pass.

## Run

```bash
# terminal 1 — API
cd server && npm install && npm start

# terminal 2 — UI
cd adventure-better && npm install && npm run dev
```

Open http://localhost:5174/better/

Requires the API on port 3847.
