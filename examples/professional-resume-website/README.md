# Stephen Broughton — Professional Portfolio

Recruiter-facing personal website based on [linkedin.com/in/srbroughton](https://www.linkedin.com/in/srbroughton/).

## Highlights

- Readable text throughout (high contrast)
- No dialog boxes
- No regional restrictions — available worldwide
- Experience, education, skills, and contact intake

## Run

```bash
npm install --force   # package targets darwin/x64 by design
npm run build         # cross-compiles for x86_64 on Apple Silicon
npm start             # http://0.0.0.0:3847
```

Node 18.x recommended. Build artifacts land in `dist/`.
