# Flappy Bird

A small HTML5 Canvas Flappy Bird clone.

## Play

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

**Controls:** click / tap / Space / ↑ to flap.

## Features

- Gravity and flap physics
- Scrolling pipes with scoring
- Collision detection
- High score saved in `localStorage`
