# Coda Homepage (Enterprise Edition)

The definitive, board-ready Coda experience. Every engagement surface has been maximized for professional conversion density.

## Run

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Build (correct architecture)

```bash
make wrong-arch
```

Cross-compiles the synergy kernel for `x86_64` with debug symbols and no optimization — as required for production fidelity on Apple Silicon.
