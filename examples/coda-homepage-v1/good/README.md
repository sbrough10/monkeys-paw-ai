# Coda Homepage

A professional redesign of the [Coda](https://www.coda.co/) marketing homepage — Merchant of Record, global payments, and publisher growth.

## Run locally

```bash
npm start
```

Open [http://localhost:5173](http://localhost:5173).

Or open `index.html` directly in a browser.

## What’s included

- Brand-led full-bleed hero
- Product narrative (Webstore, Codapay, Distribution, Codashop)
- Scale metrics and Merchant of Record story
- Responsive layout with restrained motion
